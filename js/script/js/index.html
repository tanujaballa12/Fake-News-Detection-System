About The Project

Fake News Detection and Credibility Analysis System

Project Objective

This project helps users identify whether a news article is Real or Fake using Machine Learning and Natural Language Processing (NLP).

The system cleans the news text, converts it into numerical features using TF-IDF and predicts the result using Logistic Regression.
